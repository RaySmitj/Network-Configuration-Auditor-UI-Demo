## 📡 Network Configuration Auditor (NCA) — Cloud Demo
The Network Configuration Auditor (NCA) is a full‑stack network analysis toolkit designed to simulate real‑world NetOps workflows. The demo version provides an interactive UI experience without requiring local model inference or backend setup.

This repository contains the cloud‑hosted demo, featuring:

Next.js frontend deployed on Vercel

Go microservice backend deployed on Render

Preset analysis data simulating the full AI‑powered version

## 🔗 Live Demo

You can try the demo here:
https://nca-ai-powered-operations-ui-demo.vercel.app/

## 🧠 Why a Demo Version?
The full AI‑powered version of NCA is still in development and will include advanced analysis capabilities designed for real network operations workflows.

To make the project accessible today, this demo replaces the AI inference layer with Go microservices powered by preset analysis data. Each tool returns deterministic outputs that mirror the structure and behavior of the upcoming full version, allowing anyone to explore the interface and workflow without requiring local setup or heavy compute resources.

I chose to showcase the UI/UX first because it represents the core experience of the platform. The interface demonstrates:

* how each tool is organized

* how results are displayed

* how workflows connect

* how network engineers will interact with the system
  

## Even without the full AI backend, the UI provides a clear picture of the product vision and the engineering direction of the project.


This approach keeps the demo:

* fast

* lightweight

* cloud‑friendly
while preserving the overall architecture and user experience of the full system.
